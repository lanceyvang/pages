Ride 1 · Understanding Tableau Concepts

The big ideas

15% of the examAbout 25 min

It weighs the least, but it comes first because every other lesson leans on it. Four ideas explain almost everything Tableau does.

Idea 1Dimensions and measures

A dimension is a thing you slice by. A measure is a number you add up.

Think of it like

A grocery receipt. Item names, the store, the date and the aisle are dimensions: they describe. The price and quantity are measures: you total them. Dimensions make the buckets, measures fill them.

  • Dimensions usually hold text, dates, categories, names, IDs and yes/no values. Region, Customer Name, Order Date, Product ID.
  • Measures usually hold numbers you can do math on. Sales, Profit, Quantity, Discount.
  • In the Data pane, each table lists dimensions above a thin line and measures below it.

The classic trap is a number that is really a label: zip codes, employee IDs, phone numbers. You would never add two zip codes, so they are dimensions. Tableau sometimes guesses measure.

In TableauData paneRight-click the fieldConvert to Dimension

Two special fields show up on their own: Measure Names (a dimension listing your measures' names) and Measure Values (a measure holding all their values). They appear when several measures share one axis or one table.

Idea 2Discrete blue, continuous green

This is a separate idea from dimension and measure. Keep them apart in your head.

  • Discrete means separate, countable values. It shows as a blue pill like Region and draws headers.
  • Continuous means an unbroken range. It shows as a green pill like SUM(Sales) and draws an axis.
Think of it like

Discrete is a staircase, continuous is a ramp. Steps have names. A ramp has a scale.

WhereBlue, discreteGreen, continuous
Rows or ColumnsHeadersAn axis
ColorSeparate colorsA gradient
FilterA checklistA range slider

Most dimensions are blue and most measures are green, but not always. A date can be green. A measure can be made blue. Switch it from the pill's dropdown: Discrete or Continuous.

Exam rule: pill color tells you discrete or continuous. It never tells you dimension or measure.

Idea 3Date parts and date values

  • A date part is discrete, blue. MONTH(Order Date) gives 12 headers. May means every May from every year, lumped together. Good for seasonality.
  • A date value is continuous, green. MONTH(Order Date) gives a timeline: May 2021, June 2021, on to May 2022. Each month of each year is its own point. Good for trends.
In TableauRight-click the date pillTop group = date partsSecond group = date values

When you drop a date, Tableau's default is YEAR as a blue date part, with a plus sign to drill down.

Idea 4Aggregation

Tableau never shows every row of a measure. It rolls the rows up, and the roll-up is called aggregation. The default is SUM. Others: Average, Median, Count, Count (Distinct), Minimum, Maximum, Standard Deviation, Variance and Attribute.

One viewPill dropdownMeasure (Sum)Pick another

One bar becomes four, then twelve. With SUM, the pieces still add to $2.30M. You did not change the data, only how finely it is chopped. That chopping level is the level of detail, or granularity. Every dimension in the view adds detail: on Rows, Columns, Color, Size, Label, Detail or Tooltip. Filters do not add detail. They only remove rows.

You can switch aggregation off with Analysis > Aggregate Measures. Then you get one mark per row of data. Rarely needed, often a distractor.

Exam traps
  • Green does not mean measure. Blue does not mean dimension.
  • Zip codes and IDs are dimensions even though they are numbers.
  • Adding a dimension makes more, smaller marks. The SUM total stays the same.
  • Date part (blue) combines years. Date value (green) keeps them apart.
  • The default aggregation is SUM, not Average or Count.

Ride 2 · Connecting to and Preparing Data

Getting data in

23% of the examAbout 30 min

How Tableau connects, how it combines tables, and how you tidy fields so they behave.

1.1aLive connection or extract

A live connection asks the database every time you click. An extract is a snapshot Tableau copies into its own fast file, a .hyper file.

Think of it like

Live is calling the store to ask what's in stock. An extract is a printed catalog: fast, works offline, but stale until you get a new one.

LiveExtract
Always currentCurrent as of the last refresh
Speed depends on the databaseUsually faster
Needs the source reachableWorks offline
Loads the databaseTakes load off the database

Pick an extract when the database is slow, you need to work offline, or you want to trim a huge table. Stay live when you need up-to-the-minute data from a fast database.

Make a live connectionConnect panePick the file or serverData Source pageConnection: Live (top right, the default)
Create an extractData Source pageExtract (top right)Edit for options
From a sheetDataYour data sourceExtract Data
  • Extract options: filters, Aggregate data for visible dimensions, Top N rows or a sample, and Hide All Unused Fields.
  • Refresh: Data > source > Extract > Refresh. A full refresh rebuilds everything. An incremental refresh adds only new rows, based on a field that keeps increasing, such as a date or ID.

1.1bTableau file types

FileHolds
.twbWorkbook only, no data
.twbxPackaged workbook: workbook plus data and images
.tdsData source settings only, no data
.tdsxPackaged data source: settings plus data
.hyperAn extract

Memory trick: x means the data is packed inside. tw is workbook, td is data source.

Saving metadata in a .tds. Metadata is everything about the data source except the data: the connection, renamed fields, aliases, calculated fields, groups, default formats. Save it so you or a teammate can reuse your clean setup.

In TableauRight-click the data sourceAdd to Saved Data SourcesSave as .tds

1.2Relationships, joins and unions

Think of it like

A house. The logical layer is the floor plan you see first: tables sit as boxes linked by flexible lines called relationships (people call them noodles). The physical layer is inside each room: double-click a box to go in, where you join or union tables into one.

Relationships tell Tableau how two tables match, say Orders and Returns on Order ID, without merging them up front. Tableau decides how to combine them each time, based on the fields in your view.

In TableauDrag a second table onto the canvasPick the matching fields
  • Each table keeps its own level of detail, so numbers do not double count, and unmatched rows are not lost.
  • Cardinality and referential integrity sit under Performance Options. Defaults are fine for the exam.

Joins glue two tables side by side into one wide table using a matching field.

JoinKeeps
InnerOnly rows that match in both
LeftAll left rows, plus matches from the right
RightAll right rows, plus matches from the left
Full outerEverything from both
In TableauDouble-click a tableDrag another next to itClick the Venn icon to set type

Unions stack tables on top of each other, adding rows. Use them for tables with the same columns, like Sales_Jan, Sales_Feb and Sales_Mar.

  • Drag a table directly under another until you see Drag table to union, or use New Union. A wildcard union grabs every sheet or file matching a name pattern.
  • Tableau adds columns like Sheet and Table Name showing where each row came from.
  • Column names differ? You get half-empty columns. Select them and choose Merge Mismatched Fields.

Join or relationship? Default to a relationship. It is flexible and protects against double counting. Use a join when you need a specific join type, like an inner join to drop rows without a match, or need tables merged into one physical table first. Joining detailed rows to a summary table repeats values and inflates sums.

Join or union? Join adds columns. Union adds rows.

Multiple connections. One data source can pull tables from different places, like an Excel file and SQL Server. A join across them is a cross-database join.

In TableauData Source pageConnections: AddRelate or join its tables

Blending is different: two separate data sources combined inside one sheet. The first one used is the primary (blue check), the second the secondary (orange check), with a chain-link icon on the linking field. The secondary gets rolled up to match the primary, a bit like a left join done after aggregation.

1.3Managing data properties

Each starts with a right-click on the field in the Data pane.

  • Rename a field: Rename. Only the display name changes; the source name stays underneath.
  • Alias a value: Aliases. Shows E as East without changing data. Works on dimension values only.
  • Geographic role: Geographic Role, then Country, State/Province, City, Zip Code and so on. The icon becomes a globe and Tableau creates Latitude (generated) and Longitude (generated). Unmatched places? Map > Edit Locations.
  • Data type: click the type icon (Abc, #, calendar) or Change Data Type. Number (decimal), Number (whole), Date, Date and Time, String, Boolean, plus geographic roles.
  • Default properties: Default Properties. Measures get Number Format, Aggregation, Total Using and Color. Dimensions get Comment, Color, Shape and Sort. Aliases has its own entry on the right-click menu. Dates add Date Format and Fiscal Year Start. Defaults follow the field into every sheet.
Exam traps
  • .tds saves settings only. .tdsx and .twbx include data.
  • Union means more rows. Join means more columns.
  • Relationships live in the logical layer. Joins and unions live in the physical layer.
  • Blending uses two data sources. A multi-connection source is still one data source.
  • Rename changes a field's name. Alias changes how values inside it display.
  • Incremental refresh adds new rows only. It misses edits to old rows.

Ride 3 · Exploring and Analyzing Data, part 1

Building charts

37% of the exam, with ride 4About 30 min

The biggest domain. This ride is the nine chart types the guide names. Ride 4 is filters and analytics.

Warm-upThe workspace in one minute

  • Data pane, left: your fields.
  • Columns and Rows shelves, top: what goes across and what goes down.
  • Marks card: mark type dropdown, then Color, Size, Label, Detail and Tooltip. Some types add Shape or Path.
  • Filters and Pages shelves, above the Marks card.
  • Show Me, top right: highlights charts that fit the fields you selected. Hover one to see what it needs.

Rule of thumb: Rows and Columns build the frame, the Marks card dresses it. Mark type Automatic picks bars for a dimension and measure, lines for dates, and dots for two measures.

Compares amounts across categories.

In TableauCategory to RowsSales to Columns

That gives horizontal bars. Swap Rows and Columns in the toolbar for vertical ones. Show Me needs 0 or more dimensions and 1 or more measures.

Shows change over time.

In TableauOrder Date to ColumnsSales to Rows

Shows how two numbers relate, like Sales against Profit.

Ride 4 · Exploring and Analyzing Data, part 2

Organizing and analyzing

37% of the exam, with ride 3Two rides, the densest lesson

Grouping, filtering, sorting and the analytics tools. This is a two-ride lesson: Part 1 is the episode plus groups to sorting, Part 2 is reference lines to totals. About 12 and 7 minutes of audio. A marker below shows where to stop.

2.2.1Groups

A group combines several values into one bucket, like Phones, Copiers and Fax machines into Office Tech.

From the viewSelect headers or marksPaperclip iconGroup
From the Data paneRight-click a dimensionCreateGroup
  • Include Other lumps the rest into one Other bucket.
  • The new field has a paperclip icon and acts like a dimension.
  • Great for messy data: NY, N.Y. and New York as one.

2.2.2Sets

A set splits a dimension into two buckets: In and Out. Top 10 customers versus everyone else.

In TableauSelect marksRight-clickCreate Set
  • Or right-click a dimension > Create > Set.
  • General tab hand-picks members: a fixed set that never changes.
  • Condition tab (Sales above $10K) or Top tab (top 10 by Sales) make a computed set that updates with the data.
  • Venn diagram icon. Drag it to Color for In versus Out, or to Filters to keep members.
  • Combine two sets for members in both, either, or only one.
Group or set?

A group makes many custom buckets. A set makes In and Out, and can update itself.

2.2.3Hierarchies

Stack dimensions broad to detailed so people can drill down: Category, Sub-Category, Product.

In TableauData paneDrag one dimension onto anotherName it

A plus on the pill drills down, a minus rolls up. Dates already work this way: Year, Quarter, Month, Day.

2.2.4Filters

A filter removes data from the view. Drag a field to the Filters shelf. A dimension filter has four tabs:

  • General: tick values to keep, or Exclude.
  • Wildcard: match text, like names containing Smith.
  • Condition: keep values where a rule holds, like SUM(Sales) above $1,000.
  • Top: keep the top or bottom N by a measure.

A measure filter first asks for an aggregation, then Range of values, At least, At most, or Special (null or not null).

  • Show it to users: right-click the filter pill > Show Filter. The card's dropdown changes its style: single value list, multiple value dropdown, slider.
  • Share it across sheets: pill dropdown > Apply to Worksheets > All Using This Data Source, All Using Related Data Sources, or Selected Worksheets.

2.2.5Date filters

  • Relative dates: last 3 months, this year. Moves with today's date.
  • Range of dates: fixed start and end.
  • Starting date or Ending date: one end open.
  • A discrete date part, like Years, to tick 2022 and 2023.

The orderFilters run like airport checkpoints

2.3.1Sorting

  • Manual: drag a header to a new spot, or use the toolbar sort buttons.
  • Computed: pill dropdown > Sort: by Field (Sales, descending), Alphabetic, Data Source Order, Nested, or Manual. Computed updates with the data.

2.3.2Reference lines

Mark a value on an axis, like an average or a target.

In TableauAnalytics paneDrag Reference LineDrop on Table, Pane or Cell
  • Table: one line for the chart. Pane: one per section. Cell: one per cell.
  • Or right-click an axis > Add Reference Line.
  • Values: a constant, a parameter, or an aggregation such as Average, Median, Sum, Min, Max.
  • Same dialog: reference bands, distribution bands, box plots.

2.3.3Quick table calculations

A table calculation does math on numbers already in the view, after aggregation. Like a spreadsheet formula running across your finished table.

In TableauMeasure pill dropdownQuick Table CalculationPick one
  • Running Total, Difference, Percent Difference, Percent of Total, Rank, Percentile, Moving Average, YTD Total, Compound Growth Rate, Year over Year Growth, YTD Growth.
  • The pill gets a small triangle icon.
  • Compute Using sets direction: Table (across), Table (down), Pane, Cell, or specific fields. Same calc, different direction, different answer.

2.3.4Bins and histograms

A bin turns a measure into equal-width buckets, like age bands of 10 years.

In TableauRight-click a measureCreateBinsSet size
  • The new field, like Profit (bin), is a dimension.
  • A histogram is a bar chart counting rows per bin. Select one measure > Show Me > histogram, and Tableau builds the bins for you.

2.3.5Calculated fields

A new field built from a formula, like a spreadsheet formula column.

In TableauAnalysisCreate Calculated FieldName, formula, OK

Field names go in square brackets, text in quotes, comments after two slashes. The icon shows an equals sign.

[Sales] - [Cost] SUM([Profit]) / SUM([Sales]) [First Name] + ' ' + [Last Name] UPPER([City]) LEFT([Code], 3) CONTAINS([Product], 'Chair') DATEDIFF('day', [Order Date], [Ship Date]) DATEADD('month', 3, [Order Date]) DATETRUNC('month', [Order Date]) IF [Profit] > 0 THEN 'Profit' ELSE 'Loss' END

The ratio trap. [Profit] / [Sales] divides on every row, then Tableau sums those ratios: nonsense. SUM([Profit]) / SUM([Sales]) adds first, then divides. Ratios almost always want the second. And every IF needs an END.

2.3.6Parameters

A parameter is one value the user can change, like a dial. On its own it does nothing. It matters only when something uses it.

In TableauRight-click Data paneCreate ParameterType and allowed values
  • Types: Float, Integer, String, Boolean, Date, Date and Time. Allowed values: All, List, or Range.
  • Use it in a calculated field, a Top N filter, a reference line or a bin size.
  • Show it: right-click the parameter > Show Parameter.
When to use one

When the user should pick one value that changes a calculation or setting: Top N where they pick N, a what-if growth rate, a switch between Sales and Profit. A filter removes data. A parameter only holds a value. It is not tied to any data source.

2.3.7Totals

In TableauAnalysisTotalsRow, Column or All Subtotals
  • Or drag Totals from the Analytics pane.
  • Row Grand Totals add up each row, so they appear as a new column on the right. Column Grand Totals appear as a new row at the bottom.
  • Totals follow the field's Total Using setting, Automatic by default.
Exam traps
  • Top N inside a filtered region needs a context filter.
  • Group is many buckets. Set is In or Out.
  • Computed sets and sorts update with data. Fixed and manual do not.
  • Bins are dimensions.
  • Ratios use SUM on top and bottom.
  • A parameter does nothing until a calc, filter or line uses it.
  • Row grand totals show up as a column.

Answer

Answer

D. Sort By Field can use any field in the data source, in or out of the view, and recomputes as the data changes.

Answer

C. Scope Pane computes one line per pane, so every region gets its own average.

11.You want each Category's share of total sales shown as a percentage, in the same bar chart. Right-click SUM(Sales), Quick Table Calculation, then:

Answer

Dashboards and sharing

25% of the examAbout 30 min

Turning charts into something other people can use.

3.1Formatting a view

  • Color: drag a field to Color. Discrete gets separate colors, continuous a gradient. Click Color for palette, opacity, border and halo. Edit Colors sets colors per value.
  • Fonts: Format > Font for this sheet, Format > Workbook for everything, or right-click any text > Format.
  • Shapes: mark type Shape, then a dimension on Shape. Click Shape to pick a palette per value.
  • Size: the Size slider resizes all marks, or a measure on Size sizes by value.
  • Animations: Format > Animations. On for the workbook or one sheet, set duration, Simultaneous or Sequential. They play when filters or sorts change the view.
  • Legends: appear with Color, Size or Shape. Bring one back with Analysis > Legends. Hide one from its dropdown > Hide Card.

Answer

3.Which of these filters runs first?

Answer

A. Only extract and data source filters come before context filters.

Answer

C. The primary source, the first one you drag a field from, gets a blue check mark.

Answer

B. Row grand totals total each row, so Tableau adds a column on the right-hand side.

6.You create a parameter and show its control, but nothing in the view uses it. Changing it:

Answer

D. A parameter is a value waiting to be used. A calculation, filter or reference line has to reference it before anything changes.

Answer

A. Synchronize Axis forces the secondary axis onto the same scale as the primary.

8.Which extract refresh adds only new rows?

Answer

C. Incremental pulls only rows newer than the last refresh, judged by a field that keeps increasing such as a date or an ID.

9.A Relative dates filter set to last 3 months:

Answer

B. Relative dates are anchored to today (or an anchor date you set), so the window slides forward each day.

10.Which dashboard objects can sit on top of each other?

Answer

C. Floating objects are placed by x and y position and size, so they can overlap anything beneath them.

Answer

A. Context filters run before Top N filters, so promoting Region to context makes the Top 5 rank Central customers only.
